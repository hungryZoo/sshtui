# 작업 23a: README 검증 상태 표의 호스트 키 삭제 행 수정

먼저 저장소 루트의 `AGENTS.md`를 읽고 따른다. 작업 23의 결과 가운데 한 행만 고친다. 코드는 수정하지 않는다.

## 대상 파일

- `README.md`

## 문제 위치

`7. 검증 상태`의 `검증 결과` 표에서 `호스트 키 삭제 확인 범위는 ...`으로 시작하는 수동 행.

- 상태 칸이 `확인 (macOS, PTY)`로 적혀 있다. 이 표의 수동 행은 검수자가 직접 수행한 확인을 기록하며, 검수자의 확인은 tmux 창(100x28, 임시 SSH 디렉터리와 임시 HOME)에서 수행했다.
- `ssh-keygen -R`과의 바이트 일치는 와일드카드 줄이 걸리지 않는 이름(`example.com`)에서만 성립했다. `[10.0.0.5]:2222`에서는 `ssh-keygen -R`이 `!example.com,*` 줄도 지웠고 sshtui는 그 줄을 유지했다(설계대로의 차이).

## 기대 내용

해당 행을 아래 내용으로 바꾼다(문체는 표의 다른 행에 맞춘다).

- 항목: `호스트 키 삭제: 임시 SSH 디렉터리에 평문 항목과 ssh-keygen -H로 해시한 항목이 섞인 known_hosts를 두고 x → 확인 화면 → y로 삭제. example.com은 같은 파일에 ssh-keygen -R을 적용한 결과와 바이트 일치, [10.0.0.5]:2222는 ssh-keygen -R이 함께 지우는 와일드카드 줄(!example.com,*) 1개만 차이. 백업 파일 내용과 권한(0600) 유지, HostKeyAlias 호스트의 이름 계산, 항목 없음 메시지, n 취소, 키 안내 클릭, 필터 입력 중 x 입력, 폭 96에서 필터 적용 시 키 안내`
- 상태: `확인 (macOS, tmux)`

파일 이름, 명령, 화면 문구는 표의 다른 행처럼 코드 표기로 감싼다. 다른 행과 다른 절은 건드리지 않는다.
