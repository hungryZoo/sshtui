## 변경 내용

1. 기존 서술 가운데 화면 개편으로 달라진 부분을 소스에 맞게 고친다. 확인할 항목:
   - 호스트 목록의 상세 패널 항목(패널 제목이 별칭, 본문은 `User`, `Address`, `Port`, `Key file`, `Source`. `Alias` 줄은 없음), 읽기 전용 표시(`ro`, `Read-only file`), 화면 제목 형식(`4 hosts`, `1 of 4 hosts`)
   - 접속 폼의 안내(`optional`, `required`, `inherited:`, `read-only`), 키 파일 버튼(`[ Keys F2 ]`, `[ Browse F3 ]`), `Command` 패널, `[ Connect ]`/`[ Save ]`/`[ Cancel ]` 버튼, 검증 오류 표시 조건(값이 비어 있지 않은 필드의 바로 아래 줄)
   - 변경 확인 화면의 버튼(`[ Confirm y ]`, `[ Cancel n ]`), 팝업의 버튼 문구
   - 문서 안의 화면 문구 인용이 현재 소스와 다르면 고친다(예: 이전 문구 `Ctrl+L / F2: pick from ~/.ssh`가 남아 있는지 확인)
2. `3. 사용법`에 하위 절 `마우스` 추가(`접속 실행` 앞). 목차에도 추가.
   - 동작 표(소스의 `handle_click`, `handle_scroll`, `HitMap` 등록 기준):

     | 위치 | 동작 |
     |---|---|
     | 호스트 줄 클릭 | 선택 |
     | 호스트 줄 더블 클릭(같은 칸, 400ms 이내) | 접속 |
     | 휠(목록, 변경 확인, 키 목록) | 선택 이동 또는 스크롤 |
     | 맨 아래 키 안내 클릭 | 해당 키와 같은 동작 |
     | 머리줄의 업데이트 알림 클릭 | Update 화면 열기 |
     | 폼 필드 클릭 | 포커스 이동과 커서 위치 지정(읽기 전용 필드는 포커스만) |
     | 버튼 클릭 | 버튼에 적힌 동작 |
     | 키 목록의 줄 클릭 | 선택과 확정 |
     | 팝업 바깥 클릭 | 팝업 닫기(`Esc`와 동일) |

   - 클릭은 버튼을 뗄 때 처리되고, 누른 곳과 다른 대상 위에서 떼면 취소된다는 점
   - 마우스 캡처 중에는 터미널 자체의 텍스트 선택이 동작하지 않는다는 점. 대부분의 터미널에서 `Shift`(macOS Terminal과 iTerm2는 `Option`)를 누른 채 끌면 선택 가능하다는 일반 안내를 "터미널마다 다름"이라는 단서와 함께 한 줄. `SSHTUI_NO_MOUSE=1`로 끌 수 있음
   - 종료할 때 남은 마우스 입력을 최대 250ms 동안 비운 뒤 터미널을 복원한다는 점(뒤따르는 ssh의 입력으로 들어가는 것 방지)
3. 환경변수 표에 `SSHTUI_NO_MOUSE`(비어 있지 않고 `0`이 아닌 값이면 마우스 캡처를 끔) 추가. 실행 옵션 설명과 `--help` 내용이 일치하는지 확인.
4. `검증 상태` 표 갱신:
   - 단위 테스트 수를 362개로 바꾸고 항목 설명에 "마우스 클릭 영역"을 추가
   - 수동 확인 행 추가: `마우스: tmux 창에 SGR 마우스 시퀀스를 입력해 호스트 줄 클릭과 더블 클릭 접속, 휠, 키 안내와 버튼과 필드 클릭, 팝업 바깥 클릭, 누른 곳과 다른 곳에서 뗀 경우의 취소, 종료 뒤 남는 입력 없음, SSHTUI_NO_MOUSE` / `확인 (macOS, tmux)`
   - 미검증 행 추가: `실제 마우스 장치와 터미널 에뮬레이터(Terminal, iTerm2, Windows Terminal 등)에서의 클릭과 휠` / `미검증`
   - 수동 확인 행 추가: `화면 개편: 목록, 폼, 변경 확인, 키 목록, Update 화면의 배치` / `확인 (macOS, tmux, 90x22)`. 색 표현은 `TestBackend` 단위 테스트로만 확인했다는 점을 같은 행에 적는다
5. `수동 확인 절차`에 하위 절 `마우스 확인` 추가: 실제 터미널에서 호스트 줄 클릭, 더블 클릭 접속, 휠, `n new` 안내 클릭, 폼 필드와 버튼 클릭, 팝업 바깥 클릭, `Shift`(또는 `Option`) 드래그 선택, `SSHTUI_NO_MOUSE=1`에서 터미널 기본 선택 동작, 종료 후 셸에 이상한 문자가 찍히지 않는지 확인하는 단계.
6. `개발`의 모듈 구성 표에서 `src/ui/` 설명에 테마(`theme.rs`), 버튼, 클릭 영역(`HitMap`)을 반영.
