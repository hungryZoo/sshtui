# 작업 20: README에 esc 종료와 호버 애니메이션 반영

먼저 저장소 루트의 `AGENTS.md`를 읽고 따른다. `tasks/11_readme.md`의 "작성 원칙"과 "구조 (위키형)"을 그대로 적용한다(한국어, 명사형 개조식, 비유 금지, 원 숫자 기호 금지, 범위는 `-`, 목차 앵커 일치). 가운뎃점은 화면 문구를 인용하는 코드 표기 안에서만 허용한다.

## 목표

작업 19(목록에서 `esc`로 종료, 마우스 호버 애니메이션)를 `README.md`에 반영한다. 코드는 수정하지 않는다. 모든 내용은 `src/app/mod.rs`, `src/ui/hover.rs`, `src/ui/theme.rs`, `src/ui/`의 렌더링, `src/tui.rs`와 대조해 확인한다.

## 대상 파일

- `README.md`

## 변경 내용

1. 종료 키 서술 갱신(README 전체에서 `q quit`, `q`로 종료한다는 서술을 찾아 고친다).
   - 호스트 목록 키 표: 화면 안내 `esc quit`(필터 없음)과 `esc clear filter`(필터 적용 상태, 필터 입력 중), 실제 키 `Esc`. 필터가 있으면 첫 `Esc`는 필터 해제이고 다음 `Esc`가 종료라는 점
   - `q`는 화면 안내에 없지만 계속 종료로 동작한다는 점, `Ctrl+C`는 모든 화면에서 종료
   - `수동 확인 절차`에서 "`q`로 종료" 같은 단계는 `Esc`로 바꾼다
2. `마우스` 절에 호버 설명 추가(하위 제목 없이 절 안의 문단과 표로):
   - 대상 요소와 표현 표(TrueColor 기준, `src/ui/`에서 확인): 호스트 줄, 선택된 호스트 줄, 필터 바, 폼 필드 줄, 키 안내 쌍, 주 동작 배지, 키 목록 줄, 업데이트 알림
   - 들어갈 때와 벗어날 때 각각 150ms 동안 색이 이어서 변함(진입은 ease-out). 여러 줄을 빠르게 지나가면 지나온 줄이 차례로 어두워짐
   - 포커스된 필드, 입력 중인 필터 바, 비활성 배지, 팝업 뒤 화면은 호버 표현 없음
   - 16색 모드에서는 애니메이션 없이 요소의 주 글자에 밑줄
   - 애니메이션이 진행되는 동안만 약 16ms 간격으로 다시 그리고, 끝나면 입력을 기다리는 상태로 돌아감
   - `SSHTUI_NO_MOUSE=1`이면 호버도 꺼짐
3. `색` 절의 팔레트 표에 호버용 색 3개 추가(`theme.rs`의 이름과 값 그대로).
4. `검증 상태` 표:
   - 단위 테스트 수 404개
   - 수동 행 추가: `호버: tmux 창에 마우스 이동 시퀀스를 입력해 호스트 줄 배경의 단계적 변화(진입 중간값, 완료값, 이탈 후 복귀), 선택된 줄, 필터 바, 키 안내의 호버 색, 16색 모드의 밑줄, 애니메이션 종료 후 유휴 CPU 0%` / `확인 (macOS, tmux)`
   - 수동 행 추가: `esc: 필터 적용 상태에서 첫 Esc는 필터 해제, 폼에서 Esc는 목록 복귀, 필터 없는 목록에서 Esc는 종료 코드 0으로 종료` / `확인 (macOS, tmux)`
   - 미검증 행의 "실제 마우스 장치와 터미널 에뮬레이터" 항목에 "이동 이벤트 보고와 호버 애니메이션의 체감 품질"을 추가
5. `수동 확인 절차`의 `마우스 확인`에 호버 확인 단계 추가: 호스트 줄, 키 안내, 폼 필드 위에 포인터를 올렸다 내렸을 때 밝아졌다 돌아오는지, 포인터를 가만히 두면 화면이 다시 그려지지 않는지.
