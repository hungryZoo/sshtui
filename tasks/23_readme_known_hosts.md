## 변경 내용

1. `1. 개요`의 `기능`에 한 줄 추가: 선택한 호스트의 호스트 키 항목을 `known_hosts`에서 삭제(호스트 키가 바뀐 서버에 다시 접속하기 전 정리 용도).
2. `3. 사용법`의 `호스트 목록`:
   - 키 표에 `x`(화면 안내 `x forget`) 행 추가: 선택한 호스트의 known_hosts 항목 삭제 확인 화면 열기. 필터 입력 중에는 글자로 입력됨
   - 키 안내가 화면 폭을 넘칠 때의 규칙(첫 쌍과 마지막 쌍 유지, 마지막 쌍 앞에서부터 생략)과, 폭 96에서 필터가 적용된 목록은 `r reload` 안내가 생략되지만 키는 동작한다는 점. 기존에 넘침 동작을 설명한 문장이 있으면 현재 동작으로 고친다
3. `3. 사용법`에 하위 절 `호스트 키 삭제` 추가(`변경 확인` 앞, 목차 포함). 소스와 대조해 다음을 적는다.
   - 대상 파일: ssh 디렉터리의 `known_hosts` 하나
   - 찾는 이름: `ssh -G`의 유효 설정 기준. `HostKeyAlias`가 있으면 그 값, 없으면 `HostName`(없으면 별칭), 포트가 22가 아니면 `[host]:port`. 모두 소문자로 비교. 표로 예시 3개
   - 지우는 줄: 그 이름과 정확히 같은 평문 항목(쉼표로 나열된 이름 가운데 하나라도 같으면 줄 전체), 해시된 항목(`|1|salt|hash`, HMAC-SHA1 대조)
   - 지우지 않는 줄: 주석, `@cert-authority`와 `@revoked` 줄, 와일드카드(`*`, `?`)나 부정(`!`) 패턴으로만 걸리는 줄. `ssh-keygen -R`은 와일드카드로 걸리는 줄도 지우므로 그보다 보수적이라는 점
   - 흐름: `x` → 확인 화면(제목 `Forget host key for <별칭>`, 요약 줄 `N entries for <이름> will be removed`, 삭제될 줄의 diff, 백업 안내) → `y` 또는 `enter`로 삭제, `n` 또는 `esc`로 취소
   - 결과 메시지 3종: `No entry for <이름> in <경로>`, `Removed N known_hosts entries for <이름> (backup: <경로>)`, `Cannot resolve <별칭>: <원인>`
   - 쓰기 방식: config와 같은 규칙(계획 뒤 파일이 바뀌었으면 중단, 숨김 백업 `.known_hosts.sshtui.bak`, 임시 파일 교체, 권한 유지). `4. ssh config 연동`의 `쓰기 공통 규칙`으로 링크
   - 읽기 전용 config 파일의 호스트에서도 사용 가능
   - 제한: `known_hosts2`, `UserKnownHostsFile`로 지정한 다른 파일, `/etc/ssh/ssh_known_hosts`는 대상 아님. DNS 조회를 하지 않으므로 호스트 이름과 별도 줄로 저장된 IP 주소 항목은 남음. 닉네임 없이 바로 접속한 주소는 목록에 없으므로 대상 아님
4. `변경 확인` 절: 요약 줄과 키 안내가 호스트 키 삭제일 때 달라진다는 점(`y forget`)을 한 줄로 추가하고 새 절로 링크.
5. `마우스` 절: 키 안내 클릭 설명에 `x forget`이 포함됨을 반영(목록의 클릭 가능한 안내를 나열한 곳이 있으면 추가).
6. `검증 상태` 표:
   - 단위 테스트 수를 `cargo test --offline`의 실제 결과로 갱신하고 항목 설명에 "known_hosts 항목 대조와 삭제(SHA-1, HMAC-SHA1 기준값, `ssh-keygen -H`가 만든 해시 항목)"를 추가
   - 수동 행 추가: `호스트 키 삭제: 임시 SSH 디렉터리에 ssh-keygen -H로 해시한 known_hosts를 두고 x → 확인 화면 → y로 삭제, 같은 파일에 ssh-keygen -R을 적용한 결과와 바이트 일치, 백업 파일 내용, 항목 없음 메시지, n 취소, 키 안내 클릭` / `확인 (macOS, tmux)`
   - 미검증 행 추가: `호스트 키가 실제로 바뀐 서버에서 삭제 후 재접속` / `미검증`
7. `수동 확인 절차`의 `임시 SSH 디렉터리 확인`에 단계 추가: 임시 디렉터리의 `known_hosts`에 표본 줄을 넣고 `x`로 지운 뒤 파일과 백업을 확인하는 명령. 명령은 임시 디렉터리만 대상으로 하고 실제 `~/.ssh`를 건드리지 않아야 한다(`ssh-keygen`을 쓰면 반드시 `-f <임시 파일>` 지정).
8. `9. 개발`의 `모듈 구성` 표에 `src/known_hosts/` 행 추가(`mod.rs`: 이름 계산, 줄 대조, 삭제 계획 / `hash.rs`: SHA-1, HMAC-SHA1, base64 해독. 해시된 호스트 이름 대조 전용).
