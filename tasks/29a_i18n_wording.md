# 작업 29a: 한국어 문구 2개 수정

먼저 저장소 루트의 `AGENTS.md`를 읽고 따른다. 작업 29의 결과에서 한국어 문구 2개만 고친다. 영어 문구와 동작은 바꾸지 않는다.

## 대상 파일

- `src/i18n.rs`
- 이 문구를 단언하는 테스트가 있으면 그 테스트 파일(기대 문자열만 새 문구로 수정)

## 문제 위치와 기대 문구

| 위치 | 현재 | 기대 |
|---|---|---|
| `ValidationError::InvalidPort`의 한국어 표시 | `포트는 1~65535 사이의 숫자만 허용` | `포트는 1-65535 범위의 숫자만 허용` |
| `server_password_prompt`의 한국어 | `sshtui: 서버 비밀번호 입력 가능` | `sshtui: 서버가 비밀번호를 요청할 수 있음` |

이유: 범위 표기는 `~` 대신 `-`를 쓴다. 두 번째 문구는 "서버가 비밀번호를 물을 수 있다"는 뜻이 드러나야 한다.

## 완료 조건

- `AGENTS.md`의 공통 완료 조건 3개 통과
- `src/i18n.rs`의 한국어 문자열에 `~`로 쓴 범위 표기가 남아 있지 않음(`grep`으로 확인)
- `git status`에 대상 파일만 변경으로 표시
